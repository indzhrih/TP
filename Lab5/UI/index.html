Схема переходов

Связи между формами отмечены ссылками. Каждая ссылка открывает соответствующий экран.

1. Вход и главная

Авторизация → Главная → Список задач

После входа сотрудник видит рабочее пространство и свои задачи.

2. Просмотр и отчётность

Поиск задач → Карточка задачи → Новый отчёт → Подтверждение

Если автоматическая обработка завершилась ошибкой: открыть форму ошибки.

3. Действия начальника отдела

Отдел → Назначить задачу → Подтверждение
Отдел → Оценить отчёт → Подтверждение

4. Редактирование и удаление

Задача → Редактировать → Подтверждение
Задача → Удалить → Подтверждение
Отчёты → Редактировать → Удалить

5. Администрирование

Пользователи → Добавить → Подтверждение
Пользователи → Редактировать → Удалить
